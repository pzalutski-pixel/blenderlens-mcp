# Decision records

Each file records one decision about how BlenderLens is built, and why. The files are numbered in the order
the decisions were made.

Each record states its decision as it currently stands. Changing a decision takes a new record that names the
one it supersedes, and the old record's status then names the new one.

```
# NNNN — Title
- Status: accepted | proposed | superseded by NNNN
- Date: YYYY-MM-DD
- Supersedes: — | NNNN

## Decision
## Why
```

The **Decision** section states the ruling in a few sentences a reader can act on.

The **Why** section gives the reason and, where there is one, the evidence: a reproduction, a measurement, or
a link to the specification or to Blender's source.
